# Crystal Songs

Android music player app designed for local library, simplicity & performance.

## Features

- 🪶 Simple UI, easy to navigate
- ✨ Play any audio format
- 🍃 Material 3 expressive
- 🧩 Live blur (Experimental) + Mica background blur
- 🎨 Can change app font to any .ttf font file
- 🧱 Homescreen widgets
- 📦 Only 7 megabytes
- 🟢 Android 13+ and TV support
- 📃 Live notification that shows lyrics if LRC file for music is available

Other features:
- Tag editor (Experimental)
- LRC maker
- Sound picker for other apps to use
